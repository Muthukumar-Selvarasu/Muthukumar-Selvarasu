## 🤖 Now: Forward Deployed Engineering & RAG

I am practising FDE the way the role is actually used — not wrapping an LLM API in a chat box, but owning the full path from browser to agent to retrieval to deploy.

**🎓 In session:** [Forward Deployed Engineering Bootcamp (AI System Design)](https://maven.com/boring-bot/ai-system-design) with **Hamza Farooq** on Maven — agent loops, multi-agent product architecture, RAG that scales, hosted models, caching, evals, and production deployment.

**🔍 Featured project — [Lumina Search](https://github.com/Muthukumar-Selvarasu/luminary-search)** (`lumina-search`)  
An open-source, **Perplexity-style AI answer engine**. Ask a question, get a streamed answer with clickable citations — grounded in live web search and in your own documents.

What I built and practised here:

- **Agent loop** with tools (`web_search`, `fetch_page`) and SSE streaming (`trace → sources → token → done`)
- **RAG** over uploaded Spaces: parse → chunk → embed → hybrid retrieval (vector + text) with page locators in citations
- **Deep search**: plan sub-questions, research each, merge into one citation numbering
- **Memory, threads, and a TTL'd search cache** so follow-ups stay grounded and fast
- Gateway + agent services with contracts, SLA/eval gates, and a deployable stack

I am continuing to deepen **RAG** — hybrid retrieval, grounding, citations, and evals — as a core FDE skill, not a side experiment.
